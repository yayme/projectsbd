## Problem

Students miss campus opportunities because event announcements are scattered across many channels.

## Solution

Campus Event Finder centralizes events, supports category-based filtering, and lets students bookmark sessions they plan to attend.

## Key Features

- Event discovery with filters by category and date
- Student-friendly responsive UI
- Admin event moderation workflow

## Future Improvements

- Push notifications for new events
- Recommendation engine based on student interests
